# 🌐 Site J-F

Site web vitrine développé pour présenter les services de **J-F (Escaliers Monté au Bois)**.  
Ce projet met l’accent sur un design moderne, des animations fluides et une navigation simple.

## 🚀 Aperçu

- **Site en ligne** : <https://escaliermonteaubois.ca/>
- **Repository** : <https://github.com/LeThomasMartin/Site-J-F>

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## ✨ Fonctionnalités

- Design moderne et responsive
- Compatible mobile et desktop
- Présentation des services et réalisations
- Formulaire de contact
- Animations CSS et effets visuels
